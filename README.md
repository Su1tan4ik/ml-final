## Results

Out-of-time split (80/20), 410 active zones of 594 (zones with ≥99% free-flow observations or <50 observations in the train period are excluded; the selection uses the train period only).

| Model | MAE | R² | MAPE |
|---|---|---|---|
| Naive baseline (last value) | 0.0765 | 0.707 | 4.12% |
| Random Forest | 0.0734 | 0.774 | 4.01% |
| XGBoost | 0.0730 | 0.771 | 3.97% |
| MLP Neural Net | 0.0808 | 0.757 | 4.46% |

(Numbers from `models/report.json`.) XGBoost improves on the naive "traffic in 30 min = traffic now" baseline by ~5% MAE and +0.06 R². Traffic at this spatial scale is highly persistent, so autoregressive features dominate. The strongest non-lag feature is `slot_hist_mean`: the zone's mean score in the same half-hour slot over *previous* days (causal expanding mean).

> **Leakage fixes.** An earlier version reported R² ≈ 0.99 because `diff_1` included the current target. It was replaced with `diff_2` (lag_1 − lag_2). A second leak: missing lags were filled with the segment mean *including the current row*; they are now filled with the mean of past values only (`scripts/feature_engineering.py --rebuild-lags`).

**Classification (congested = score > 2.0, ~8% positive class).** No class re-weighting; the probability threshold is tuned for F1 on a time-ordered validation split (last 15% of train).

| Model | Accuracy | F1 | Precision | Recall | Threshold |
|---|---|---|---|---|---|
| Naive (congested now → congested in 30 min) | 94.8% | 0.69 | 0.73 | 0.66 | — |
| XGBoost | 95.3% | **0.73** | 0.74 | 0.72 | 0.375 |
| Random Forest | 95.1% | 0.73 | 0.71 | 0.75 | 0.325 |

Accuracy is inflated by class imbalance; F1/precision are the meaningful metrics. `/api/predict` uses the XGBoost regressor + classifier with the tuned threshold.

**What-if analysis (model-based, associational — not causal).** Only exogenous inputs are changed; the current traffic state is kept fixed:

| Scenario | Change in predicted score |
|---|---|
| Peak spreading: rush-hour observations re-timed to 14:00 | −2.6% |
| Clear weather (no precipitation) | ≈0% |
| Heavy rain (5 mm/h) | −0.2% (≈0: the model finds no rain effect on this data) |
| Persistence: +20% congestion now | +10.4% → about half of a shock persists 30 min later |

Peak spreading changes only the clock features; `slot_hist_mean` (the zone's typical score for the *original* rush slot) is kept, so −2.6% is a lower bound of the time-of-day effect, not an estimate of what flexible hours would achieve.

The dashboard map (`static/map_data.json`) and the hotspots table (`models/streets.csv`) are regenerated by `train.py` on every retrain.
