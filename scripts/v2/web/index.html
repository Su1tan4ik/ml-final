Прогноз по улице

Наблюдения (балл, взвешенный по длине участков улицы) и последний прогноз модели XGBoost на +30 / +60 / +120 минут. Улицу можно выбрать здесь или кликнуть по ней на карте.

Улица:

Модели

XGBoost-регрессия (балл через h×30 мин) и классификатор «будет пробка» (балл ≥ 5.5) для каждого участка и направления. Проверка честная: разбиение по времени (последние 20% срезов — тест), активные участки и порог классификатора выбираются только на обучающем периоде. Сравнение с базовыми прогнозами: «как сейчас» и «типично в это время».

Регрессия: ошибка прогноза балла (MAE, меньше — лучше)

Классификация «будет пробка» (F1, больше — лучше)

Важность признаков (доля gain, горизонт )

Рекомендации

Для самых загруженных улиц прогноз модели раскладывается на вклады признаков (TreeSHAP, XGBoost pred_contribs). История пробок всегда даёт основной вклад — это честно показано. Тип рекомендации выбирается по «структурной» части (без истории и координат): соседние участки → 🚦 светофоры, время суток → ⏰ час пик, параметры дороги → 🛣 узкое место, погода → 🌧, поровну → ⚡.

Сбор данных

Каждые 30 минут сервер скачивает 2 226 тайлов пробок Yandex (zoom 16, ≈1.7 м/пиксель), классифицирует цвет каждого пикселя и привязывает его к участку дороги OSM и направлению движения.
